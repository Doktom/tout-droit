# Tout Droit

Petit jeu de plateforme en HTML/JS (un seul fichier, `tout-droit.html`), dans l'esprit d'Alt-F4 : simple en apparence, plein de pièges, avec un narrateur (le Soleil) qui se moque de toi.

- 2 niveaux, décrits en JSON dans le fichier (`<script type="application/json" id="level-N">`)
- Contrôles : flèches / ZQSD, Espace pour sauter, R recommencer, M son, Échap pause
- `?niveau=2` dans l'URL pour démarrer directement au niveau 2

Ouvrir `tout-droit.html` dans un navigateur, ou lancer `python -m http.server`.
