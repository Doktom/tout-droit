# Tout Droit

Petit jeu de plateforme en HTML/JS (un seul fichier, `index.html`), dans l'esprit d'Alt-F4 : simple en apparence, plein de pièges, avec un narrateur (le Soleil) qui se moque de toi.

- 3 niveaux, décrits en JSON dans le fichier (`<script type="application/json" id="level-N">`)
- Contrôles : flèches / ZQSD, Espace pour sauter, R recommencer, M son, Échap pause
- `?niveau=2` ou `?niveau=3` dans l'URL pour démarrer directement à un niveau

Ouvrir `index.html` dans un navigateur, ou lancer `python -m http.server`.
